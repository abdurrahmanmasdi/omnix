## Proposed decisions

- next-intl without locale URL segments; official setup reviewed before install: https://next-intl.dev/docs/getting-started/app-router.
- Preference order: saved user → NEXT_LOCALE → supported Accept-Language → tr. Server render uses cookie/browser because access tokens are held in memory; restored authenticated identity applies its saved preference during hydration and synchronizes HTML/cookie.
- Self endpoint PATCH /users/me/locale is independent of N2. Language save failures preserve the current choice; no session reset or logout.
- Europe/Istanbul timezone retained; local Arabic font shipped with OFL license.
- Dynamic clinic/user/patient content and AI configuration values remain data, including patient-facing default messages. Brands, protocol examples and technical filenames remain literal.
- Error text fallback remains available for unknown codes and legacy rows. HTTP status codes translate generic errors while existing specific codes remain intact.
